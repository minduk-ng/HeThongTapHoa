# Chuẩn Hóa Toàn Diện CI Xanh 100% với PHPStan Level 7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đạt trạng thái 100% kiểm tra CI xanh (All Green) trên GitHub Actions với PHPStan Level 7, loại bỏ toàn bộ lỗi lệch format Pint & Prettier và tinh chỉnh ma trận PHP ổn định.

**Architecture:** Sử dụng trực tiếp các công cụ kiểm tra định dạng và phân tích tĩnh có sẵn trong dự án (Pint cho backend, Prettier cho frontend, PHPStan Level 7 cho types check), giữ nguyên 100% logic nghiệp vụ hiện có. Tinh chỉnh workflow GitHub Actions ma trận PHP 8.3 & 8.4.

**Tech Stack:** PHP 8.3/8.4, Laravel 13, Laravel Pint, PHPStan / Larastan 3.x (Level 7), Node 22, Prettier, ESLint, TypeScript 5.7, Pest 4.x.

## Global Constraints

- **PHPStan Level:** Tuyệt đối giữ nguyên `level: 7` trong `phpstan.neon`, không hạ level, không dùng ignore tags mới.
- **Business Logic:** Chỉ format code style, không thay đổi logic xử lý hay signature của bất kỳ controller/service nào.
- **Exit Code:** Mọi bước kiểm thử trong quy trình CI phải trả về exit code 0.
